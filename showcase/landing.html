Five examples, one learning path

Edit the source and try the result. These same components appear in the tutorial, playgrounds, documentation and Storybook. Card examples need no MoonBit compiler download. The contact directory also shows the MoonBit code that filters and paginates its data.

Use Tutuca in your project

Start with a portable card, or add Tutuca to a MoonBit project and generate compiled components from the same file format.

moon add marianoguerra/tutuca
