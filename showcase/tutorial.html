From a small control to a document workspace

Five practical components, using the same sources you can inspect in Storybook and reuse in a MoonBit application.

Read a component

spec: declares fields and contracts. logic: defines updates and derived values. view: describes the interface. Named fixtures: show useful states; tests: checks interactions. Start by using each component, then change its source.

Connect a real application

The directory uses a host handler to filter contacts before pagination. The workspace uses delayed load/save handlers backed by session-local memory. Your application registers those handlers against its own services. A component states the job; the host supplies the implementation.

Read the MoonBit integration guide or explore focused language and integration examples in the playgrounds' Reference groups.
